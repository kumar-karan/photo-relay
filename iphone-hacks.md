# iPhone 17 Pro — Hacks & Smart Shortcuts (coming from Samsung)

A Samsung-refugee's cheat sheet. Grouped by the physical buttons that are new to you,
then automations, then quality-of-life settings.

---

## 1. The three side buttons you didn't have on Samsung

### 🔘 Action Button (the one where the mute switch used to be)
`Settings → Action Button` — swipe to pick ONE default action. Best picks:
- **Shortcut** → point it at any custom Shortcut (this is the power move — see §3).
- Or Camera / Flashlight / Voice Memo / Translate / Focus mode.

**Hack:** Make it a *menu* instead of one action — build a Shortcut called "Action Menu"
using the **Choose from Menu** block (Camera / LocalSend / Torch / Voice Memo), assign it
to the Action Button → one press = mini launcher.

### 📷 Camera Control (the glossy capacitive button, lower-right side)
- **Half-press** → focus / open a slider (zoom, exposure, depth, styles). Swipe on it to adjust.
- **Light double-press** → cycle between controls.
- Set it to launch a **third-party camera** too: `Settings → Camera → Camera Control`.

### 🔊 The Samsung muscle-memory fixes
- Mute is now a *press* of the Action Button, not a physical flip — glance at the Dynamic Island bell.
- **Screenshot** = Side button + Volume Up (not Volume Down + Power like Samsung).
- **Force restart** = Vol Up → Vol Down → hold Side button.
- **Power off** = hold Side + either Volume (or `Settings → General → Shut Down`).

## 2. Back Tap — the hidden Samsung-Edge-panel replacement
`Settings → Accessibility → Touch → Back Tap`
- **Double tap** back of phone → e.g. Screenshot.
- **Triple tap** → run any Shortcut (e.g. your monthly LocalSend transfer!).
Great for one-handed actions.

## 3. Shortcuts & Automations (the real superpower vs Samsung)

### ⭐ Monthly photo-transfer Shortcut (ties into the backup plan)
1. Shortcuts app → **+** → name it "Monthly Backup".
2. Add **Find Photos** → filter *Date Taken* is *in the last 30 days* (and *Media Type is Image/Video*).
3. Add **Share** (or "Save to Files" if LocalSend watches a folder).
4. Run it → pick LocalSend in the share sheet → sends the month in one go.
5. Assign it to the **Action Button** or **Triple Back Tap**.

### ⏰ Time-based automation (semi-auto reminder)
`Shortcuts → Automation → +` → **Time of Day** → 1st of every month →
run "Monthly Backup" (set *Ask Before Running* on so it doesn't fire blindly).

### Other automations worth setting
- **Arrive home / connect to home WiFi** → turn on Low Power off, open something, etc.
- **Connect to car Bluetooth** → start Maps + a playlist.
- **Battery drops below 20%** → enable Low Power Mode automatically.
- **NFC tag** on your desk → toggle a Focus mode.

## 4. Camera / photo pro-tricks (you have real hardware now)
- **Photographic Styles** (iOS 26) are now *editable after the shot* — pick a base look in
  `Settings → Camera → Photographic Styles`. Non-destructive.
- **ProRAW / ProRes**: `Settings → Camera → Formats` — toggle for RAW editing / pro video.
  (⚠️ huge files — leave OFF for everyday shots you're backing up unlimited.)
- **Camera Control zoom**: swipe the capacitive button instead of pinching.
- **Volume Up = shutter** (also starts video if held). Great for stability.
- **QuickTake**: hold shutter for instant video without switching modes.
- **Level & grid**: `Settings → Camera → Composition` → turn on Grid + Level.
- **Live Text**: long-press any text in a photo/camera to copy, translate, or dial it.

## 5. Quality-of-life settings to flip on day one
- **Charging limit** to protect battery: `Settings → Battery → Charging → 80% / 90%`.
- **Haptic keyboard**: `Settings → Sounds & Haptics → Keyboard Feedback → Haptic`.
- **Type to Siri / Live Translation**: `Settings → Apple Intelligence & Siri`.
- **Dynamic Island**: long-press a live activity to expand; drag to dismiss.
- **Reachability** (top of screen hard to reach): swipe **down** on the bottom edge.
- **StandBy mode**: charge on its side in landscape → clock/widgets dashboard.
- **Faster typing**: slide finger across the space bar to move the cursor.
- **Undo**: shake the phone, or three-finger swipe left. Redo = three-finger right.
- **Scientific calculator**: rotate to landscape (or the new Math Notes in the Calculator app).
- **Offload unused apps**: `Settings → App Store → Offload Unused Apps` to reclaim space.
- **Emergency**: hold Side + Volume → SOS / Medical ID. Set up Medical ID in Health app.

## 6. iOS 26 / Apple Intelligence goodies
- **Live Translation** in Messages, FaceTime, and Phone calls.
- **Call Screening & Hold Assist** — phone answers unknown callers / waits on hold for you.
- **Clean Up** in Photos — remove photobombers (like Samsung's Object Eraser).
- **Genmoji + Image Playground** — make custom emoji/images.
- **Writing Tools** — proofread/rewrite text anywhere (select text → Writing Tools).
- **Visual Intelligence** — point Camera Control at something to search/identify it.
