Photo Relay — three UI directions

Each mockup below is a live, self-contained rendering of the same moment: a relay mid-run at 112 of 138 files, 1.94 GB, 88 MB/s, 1:24 left. Pick a letter and it gets built into the app.

A — Control Room B — Focused Relay C — Split Deck

Direction A — Control Room

Dense console Constrained 1080px column, dense stat strip, monospace numerics. For someone who reads state at a glance and wants maximum information per glance.
  • Structure single column, 6 stage chips on a connected rail, stat strip, files + milestones + history below.
  • Stretch fix max-width caps the canvas; everything sits on cards instead of full-bleed bands.
  • Flow fix seamless one-directional pulse, no visible reset.

Direction B — Focused Relay

Single hero Narrow 820px column. The device chain is the emotional centre; detail collapses into a bottom sheet. For someone who wants the app to feel calm, not technical.
  • Structure hero chain, progress block, recent files, collapsible detail sheet.
  • Stretch fix 820px column inside a 1280px window, nothing spans the full width.
  • Flow fix repeating-gradient whose period equals its tile width, so one tile shift is a pixel-identical frame. Packets wrap entirely off-clip.

Direction C — Split Deck

Workspace tool Left nav rail plus a two-column working surface: live relay on the left, streaming file list on the right. For someone who treats it as a tool they live in.
  • Structure persistent sidebar with pinned run status, two-column work area, secondary tabs.
  • Stretch fix the sidebar takes the width, so the main area keeps a readable measure.
  • Flow fix seamless directional flow with staggered packets.
