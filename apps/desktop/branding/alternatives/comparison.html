Photo Relay - Icon Alternatives

14 concepts for the macOS app mark and dock icon. Each ships a 24px mark.svg (stroke based, currentColor) for in-app use and a 1024px icon.svg plus rendered icon-1024.png (RGBA, transparent squircle corners) for the Tauri icon flow.

Each mark is shown at 16, 24, 48, 128, 256 and 512 where it runs, so small-size legibility is visible directly. Geometry is adapted from lucide, tabler and phosphor where a suitable icon existed, then redrawn on one 24 unit grid.
