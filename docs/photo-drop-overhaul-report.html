1. Overview & Resolved Failure Modes

In-App Owner Dashboard

Integrated native OwnerActivity directly into the launcher APK. Tapping "Open live dashboard" launches the dashboard inside the Android app over direct loopback (127.0.0.1:8080), completely independent of external Cloudflare tunnels or browser tabs.

Live Multi-Client Telemetry

Tracks live guest sessions from cookies, batch manifests, and active socket streams. Displays device identities (iPhone, Pixel, Mac), client IPs, active session badges, and exact per-file upload progress and transfer speed.

Process Lifecycle & Port Lock

Replaced toybox pkill/pgrep with robust /proc/[0-9]*/cmdline scanning and tiered ensure_dead (SIGTERM → 4s grace → SIGKILL). Eliminates stale zombie Python processes holding port 8080 across app restarts.

Privacy & Token Hardening

Token-gated /healthz diagnostics. Unauthenticated probes receive only {"ok": true}. The server binds 127.0.0.1 locally, preventing accidental LAN exposure on untrusted Wi-Fi.

4. Core Hardening Implementation

Process Scanning (ensure_dead)

ensure_dead() {
  local needle="$1"
  kill_matching "$needle"
  local tries=0
  while [ $tries -lt 20 ]; do
    [ -z "$(pids_matching "$needle")" ] && break
    sleep 0.2
    tries=$((tries + 1))
  done
  if [ -n "$(pids_matching "$needle")" ]; then
    kill_matching "$needle" -9
  fi
}

Scans /proc/[0-9]*/cmdline directly. Bypasses Android Toybox pkill limitations with setsid processes.

Loopback & Proxy Detection

def _is_direct_loopback():
    if (request.headers.get("X-Forwarded-For")
            or request.headers.get("X-Forwarded-Host")
            or request.headers.get("X-Forwarded-Proto")):
        return False
    return request.remote_addr in {"127.0.0.1", "::1", "localhost"}

Cloudflare tunnel proxies traffic to 127.0.0.1. Checking proxy headers guarantees external requests cannot spoof local loopback permissions.
